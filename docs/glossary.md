# 术语表

| 术语 | 含义（MAHEA 用法） |
|------|-------------------|
| Harness | 包围模型的工程基础设施：上下文、约束、工具、反馈与治理等 |
| Kernel | 薄运行时入口：生命周期、回合、能力挂载 |
| Layer | 从内核拆出的 context / orchestration / action |
| Cap | 能力扩展面：hook / tool / plugin / skill |
| Hook | 生命周期切入点（如工具调用前后） |
| Skill | 面向协作与工程流程的可复用工作说明（`caps/skills`） |
| Stock | 外部素材的可追溯登记库 |
| Turn | 一次用户/系统输入驱动的处理回合（中性术语） |
| Interop | 跨 Harness / 协议的适配与翻译 |
| Assurance | 评测、观测、治理、沙箱等保障层合称 |

避免将某一厂商内部私有名词当作 MAHEA 唯一官方术语；融合见 [harness-fusion.md](harness-fusion.md)。
