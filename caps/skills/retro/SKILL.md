# Skill: retro

## 职责

在阶段结束、PR 提交前或里程碑收尾时，做结构化复盘与自查，降低违规与遗漏。

## 何时使用

- 计划中某一任务阶段完成时
- 准备 commit / PR 之前
- 审计或大规模目录建设之后

## 输入

- 本阶段目标与实际改动摘要
- （可选）上一阶段遗留问题

## 输出

- 已完成 / 未完成 / 有意延后 列表
- 自查清单勾选结果
- 风险与下一步建议（一两句）

## 自查清单

- [ ] 已阅读本阶段相关 `rules/` 文件
- [ ] 无数字前缀命名；无 `template/` 目录
- [ ] 外部引用已在 `stock/` 登记或标记 `pending`
- [ ] 未引入未经确认的第三方依赖
- [ ] 模块 README 仍含职责、接口、关系（若本阶段新建模块）
- [ ] 未破坏 `LICENSE` 与根 `README.md` 既有定位句
- [ ] 未把 MAHEA 写成单一 Harness 复刻
- [ ] 深度停留在约定范围（文档 + 占位，除非另有确认）

## 与规则的关系

清单条款与 `rules/AGENTS.md`、`SOURCE_POLICY.md`、`NAMING.md`、`CONTRIBUTING.md` 对齐。发现违规应先修复再进入下一阶段。
